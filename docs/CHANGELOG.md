## 채택하지 않은 주요 안 (이유)

- 서점 이북 DRM 해제: 저작권법상 불가.
- 독립 스크립트+서버 이미지(FBInk): KOReader 플러그인이 절전·화면·Wi-Fi를 대신 처리하므로 불필요.
- 캘린더 공개 설정: 일정 전체 노출 → 비공개 iCal 주소 사용.
- 기기에서 구글 로그인(OAuth): 토큰 관리가 복잡 → Apps Script를 중간에 둠.
- 비밀값 파일을 공개 GitHub에 잠시 올리기: 커밋 기록에 남음 → 캘린더 일정 제목으로 전달.
- 두 번 터치로 취소선: KOReader가 모든 터치를 지연시킴 → 네모 칸 한 번 터치.
- 가로 시계 더 크게: '가분수'처럼 균형이 무너짐(사용자 판단) → 2.2cm.
- 알림 때 조명 깜빡임, 10분 내내 깜빡임: 사용 환경·배터리.
- 동기화·알림 깨우기 따로 예약: RTC가 지난 시각으로 설정돼 못 깨어날 위험.
- 잔상 정리(정기 전체 새로 고침), 오늘 표시 A안(얇은 테두리): 사용자 결정.
- 날씨·미세먼지(11/7 보류), 액자 플러그인(11/2 보류), 주식 화면(검토만), 다른 기기 적용(정보 수집, 실행 계획 없음).
